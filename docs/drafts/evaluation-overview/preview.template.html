综合分的口径

默认采用 0.5 × Kev Transfer-v9 accuracy + 0.5 × JevBench accuracy，计算使用发布结果中的未四舍五入数值。Kev Transfer-v9 内部沿用原有的逐题平均；整个 Kev Transfer-v9 套件和整个 JevBench 套件各占一半。

  • 这个数值是两套准确率的草稿汇总，不是 Artificial Analysis Intelligence Index，也不代表通用智能或所有模型的全球排名。
  • NLL、Brier、ECE 保留在原表中。将准确率、概率质量和校准误差混成单一总分，需要另行定义归一化和权重。
  • JevBench 使用 231 个公开开发题；Jev 1.13.0 的 JevBench 值来自已发布结果，Kev Transfer-v9 值来自本地 API 评测。
  • 4B pointer 与 direct-token 的差距较小；两套等权时 direct-token 在前，每题等权时 pointer 在前。当前汇总文件不足以计算模型间差异的配对置信区间，排序不表示统计显著性。
